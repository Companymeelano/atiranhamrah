# آتیران همراه — نمایشگر مدیریت دیتابیس (اندروید)

نسخه ۲.۰.۰ — اپلیکیشن اندرویدی **فقط-خواندنی** برای اتصال **مستقیم** به
**Microsoft SQL Server** و مشاهده و مدیریت داده‌های دیتابیس.

## امکانات

- **اتصال مستقیم به SQL Server** با درایور رسمی JDBC مایکروسافت (TLS رمزنگاری‌شده)
- **ورود در ابتدای برنامه** فقط با نام کاربری و رمز عبور SQL Server — بدون نیاز به
  CPUID/توکن/فعال‌سازی دستگاه. اعتبارنامه‌ها همان اطلاعات ورود دیتابیس‌اند.
- «مرا به خاطر بسپار» — ورود خودکار در اجرای بعدی (رمز در حافظه خصوصی اپ ذخیره می‌شود)
- **مرور همه جداول** دیتابیس (نام، اسکیما، تعداد رکورد)
- **نمای کلی دیتابیس**: نسخه SQL Server، تعداد جداول، مجموع رکوردها، حجم دیتابیس
- **مشاهده رکوردهای هر جدول** به‌صورت صفحه‌بندی‌شده (۵۰ رکورد در صفحه)
- **جستجوی سرور-محور** در ستون‌های متنی هر جدول (کوئری پارامتری و امن)
- جزئیات کامل هر رکورد با یک ضربه
- رابط کاربری Material 3 راست‌به‌چپ با تم سبز آتیران

## راه‌اندازی

1. اپ را نصب و اجرا کنید.
2. در صفحه ورود، سرور (`37.143.147.19`)، پورت (`1433`)، نام دیتابیس (`Atiran2`)
   و نام کاربری/رمز SQL Server را وارد کنید (سه فیلد اول پیش‌پر شده‌اند).
3. «مرا به خاطر بسپار» را روشن بگذارید تا دفعات بعد ورود خودکار باشد.
4. بعد از ورود، لیست جداول دیتابیس نمایش داده می‌شود؛ هر جدول را برای مشاهده
   رکوردها باز کنید.

### پیش‌نیازهای سمت سرور

- **TCP/IP** در SQL Server فعال باشد (`SQL Server Configuration Manager`
  → Network Configuration → TCP/IP Enabled) و پورت (پیش‌فرض 1433) در
  فایروال باز باشد.
- کاربر SQL Server باید دسترسی حداقل `db_datareader` روی دیتابیس داشته باشد.
- SQL Server Authentication (حالت Mixed) فعال باشد.

## امنیت — حتماً بخوانید

اتصال مستقیم موبایل به SQL Server عمومی روی اینترنت، ذاتاً حساس است:

1. **یک کاربر فقط-خواندن بسازید** و به‌جای حساب مدیر در اپ استفاده کنید:
   ```sql
   CREATE LOGIN app_reader WITH PASSWORD = '<رمز قوی>';
   USE Atiran2;
   CREATE USER app_reader FOR LOGIN app_reader;
   ALTER ROLE db_datareader ADD MEMBER app_reader;
   ```
2. **فایروال** را طوری تنظیم کنید که پورت 1433 فقط برای آدرس‌های مجاز باز باشد.
3. اتصال با TLS رمز می‌شود اما گواهی سرور تایید نمی‌شود
   (`trustServerCertificate=true`).
4. رمز عبور در صورت فعال‌بودن «مرا به خاطر بسپار» در حافظه خصوصی اپ ذخیره
   می‌شود و پشتیبان‌گیری اپ (`allowBackup=false`) غیرفعال است.
